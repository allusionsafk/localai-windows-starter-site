Playback philosophy

Reference first. Enhancements on purpose.

The default path is intentionally conservative. Upscaling, cleanup/debanding, RTX Video HDR, RTX Super Resolution, motion smoothing, and HDMI bitstream are explicit choices rather than silent defaults.

  1. 1Reference

    Start from a reference-first playback path without silently enabling interpolation, cleanup, HDR conversion, or RTX Super Resolution.

    native cadence · decoded PCM default

  2. 2Enhance deliberately

    Turn on high-quality scaling, compression cleanup, RTX Video HDR, RTX Super Resolution, or motion smoothing per video when they are useful.

    opt-in processing

  3. 3Fall back when measured

    If display-synchronised interpolation is measurably unstable and harming playback, the managed path can fall back to native cadence instead of persisting with visible frame problems.

    measured motion guard

What changed in 0.3.2

Two playback defects, measured and corrected.

The 0.3.2 release was driven by observed renderer and presentation behaviour rather than by changing presets on paper.

  • Compatibility now takes the compatibility path

    The Compatibility preset now selects the documented D3D11 renderer path instead of accidentally continuing through the managed NVIDIA Vulkan path.

  • Motion smoothing can protect itself

    Gentle and Smooth motion now require a settling window, measurable display instability, and measurable playback harm before automatically returning to native cadence.

  • Playback Diagnostics ships with the installer

    The Start menu includes Adaptive Media Playback Diagnostics, which launches the production plan, reads renderer/decoder/refresh/frame-timing state over mpv IPC, and writes a support report locally.

  • Settings remain separate from the install

    User settings remain under %LOCALAPPDATA%\AdaptiveMedia\settings.json and survive upgrades.

Measured boundary

Strong claims stop where the measurements stop.

The release was certified on the current RTX 4080 Laptop validation machine. That is evidence for that path, not a promise about every display, receiver, cable, driver, or HDR chain.

measured · explicit · reversible

  • Certified managed NVIDIA path

    The published build was certified with Vulkan/winvk/FIFO plus NVDEC and steady-state zero output drops, zero decoder drops, and zero delayed frames on the validation machine.

  • External HDR switching is hardware-dependent

    External HDR-TV switching behaviour has not been claimed as universally verified across hardware chains.

  • HDMI bitstream and Atmos remain optional

    Decoded PCM remains the safe audio default. HDMI bitstream/Atmos passthrough is still hardware-dependent and is not presented as universally verified.

  • Dolby Vision wording stays literal

    mpv/libplacebo Dolby Vision processing is not described as native Windows Dolby Vision or Profile 7 FEL passthrough.
