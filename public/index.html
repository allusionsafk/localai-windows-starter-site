How it works

Three steps, one evening.

The installer does the fiddly parts. You mostly wait, and restart once if Windows asks.

  1. 1Download AFK AI

    One file. Double-click it and the guided installer opens in its own window.

    Install AFK AI.cmd

  2. 2Run the installer

    It checks your PC, installs what is missing, and picks a model that fits your graphics card.

    Docker · Python · your model

  3. 3Open it and chat

    When setup finishes, AFK AI takes you to the Control Center. After that, reopen it from the Start menu.

    127.0.0.1:3000

First setup is not instant, and not fully hands-off. It downloads several gigabytes, Docker Desktop usually has to be opened once so it can finish its own setup, and Windows may ask to restart. Docker also needs hardware virtualization enabled in your PC firmware, which is where setup stops if it is switched off.

Control Center

One window to run the whole thing.

Start it, stop it, check that it is healthy, and copy a diagnostic report when something looks wrong. No terminal required.

  • Live engine status

    See at a glance whether the model engine and services are up, before you wonder why chat is slow.

  • System health

    A health check you can re-run any time. It reports passing, warnings and failures rather than one vague light.

  • This machine at a glance

    Your graphics card and memory, and which model AFK AI recommends for them.

  • Copy Diagnostic Report

    One button produces a support report designed to leave out your chats, documents, prompts, credentials and file contents.

Local by default

It runs on your machine.

The model runs on your own graphics card. There is no AFK AI cloud account or subscription; Open WebUI keeps its local account and chat database on your PC.

loopback-only by default

  • Nothing is opened to your network

    Every AFK AI port binds to 127.0.0.1, which is your own PC and nothing else. Reaching it from your phone is a separate, deliberate step.

  • Start it when you need it

    AFK AI does not need to run all the time. Use the Control Center when you want local AI running, and keep it out of the way when you do not.

  • Diagnostics stay clean

    The report you send for help is designed to leave out your chats, documents, prompts, credentials and file contents.

  • What does use the internet

    Setup and model downloads use the internet. If you switch web search on, SearXNG sends search queries to external search providers. Local model inference and the chat database stay on your PC.

Try it on your own PC.

You are one of the first people to run this. If something breaks, press Copy Diagnostic Report in the Control Center and send it over.
