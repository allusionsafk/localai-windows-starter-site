Windows 11 · NVIDIA GPU · loopback-only by design

Your own private AI, running on your own PC.

localai is a self-hosted, ChatGPT-style workspace for Windows: a chat UI, a private web-search engine, and local voice — with models served by Ollama on your own GPU. Nothing leaves your PC unless you explicitly turn it on. One double-click to install.

What you get
  • Chat UI — Open WebUI at localhost:3000
  • Private web search — SearXNG at localhost:8080
  • Local voice — Kokoro TTS + Whisper, CPU-only
  • Local images — optional ComfyUI in-chat

Loopback-only and manual-start by default. Share to your own devices only via an explicit Tailscale opt-in — never a raw LAN bind.

Install

Three ways in. Pick your comfort level.

Windows 11 with an NVIDIA GPU and Docker Desktop. The installer picks models that fit your hardware — see capability tiers.

Easiest — no typing

Download Install Local AI.cmd from the latest release and double-click it. Windows shows a security box because the file was downloaded — choose More info → Run anyway. It vets your GPU, picks fitting models, and opens your chat at 127.0.0.1:3000.

Download installer
# After it finishes, start/stop with no typing:
Start Local AI.cmd
Stop Local AI.cmd

# They live in %USERPROFILE%\localai

Guided installer (the Friend Bootstrapper)

Vets your hardware, picks fitting models, brings the stack up loopback-only, then hands off to health checks. The bootstrap is pinned and fails closed — it verifies the download against a released tag's commit SHA (or zip SHA-256) before running.

# In Windows PowerShell — download then run the pinned bootstrap:
Invoke-WebRequest https://raw.githubusercontent.com/allusionsafk/localai-windows-starter/master/installer/bootstrap.ps1 -OutFile "$env:TEMP\localai-bootstrap.ps1"
powershell -ExecutionPolicy Bypass -File "$env:TEMP\localai-bootstrap.ps1"

Manual bring-up

For when you already have the repo checked out and want each step explicit. Requires Python 3.12+.

pip install -e .
copy .env.example .env        # then set SEARXNG_SECRET to a long random string
localai start                 # Ollama (native) + the compose services
localai health                # end-to-end checks
# open http://localhost:3000  → create your admin account on first visit

Security contract

Local-first, and locked down by default.

  • No network exposure by default. Every port binds to 127.0.0.1. No raw LAN or 0.0.0.0 binds.
  • No autostart. No scheduled tasks, no Docker restart policies, no auto-launch. Starting the stack is always a manual choice.
  • Secrets stay local. .env is gitignored; you generate your own SEARXNG_SECRET.
  • First account = admin. Stored only in the local database on your PC.
  • Sharing is an explicit opt-in. Reach it from your phone via Tailscale Serve — private to your tailnet, never public.
Guardrails

Verify it, don't trust it.

The kit ships checks so the secure posture can't silently drift:

Capability tiers

It sizes the model to your card.

VRAM is the binding limit. Assuming q8_0 KV cache host-side, each tier's ceiling model stays on the GPU. Pick your VRAM to see the fit.

Honest tradeoff: large context and large models can still spill to CPU when VRAM is insufficient, which slows generation. localai model-scout shows the picks and the tradeoffs for your box.

The localai CLI

One command instead of a folder of scripts.

A single Python entry point drives the whole stack. Run localai --help for the full list.

localai vetProbe GPU / VRAM / CPU / RAM / disk → a capability tier.
localai start · stopBring the stack up or down.
localai healthEnd-to-end health checks (Ollama, services, search).
localai dashboardThe pywebview Control Center on localhost:8765.
localai model-scoutRecommend models that fit your VRAM budget.
localai webui-seedSeed Open WebUI defaults (model, context length).
localai warm · perf · powerWarm models; performance and battery guards.
localai updateUpdate models, images, and Modelfiles.
Troubleshooting

The usual first-run snags.

Windows blocks the installer

SmartScreen shows a security box because the file was downloaded — click More info → Run anyway. If there's no "Run anyway" option at all, Smart App Control is on and blocks unsigned scripts outright — turn it off under Windows Security → App & browser control, or use the PowerShell install method.

Docker Desktop needs one launch first

If setup can't reach Docker, open Docker Desktop once and let it finish starting, then re-run the installer.

My GPU is AMD or Intel

This stack is NVIDIA/CUDA-only. On AMD/Intel it runs CPU-only and is slow — the installer says so plainly rather than pretending otherwise. See the CPU tier.

First chat is slow / no model loaded

Cold-loading a model reads it off disk into VRAM. The installer picks a model that fits your card; use localai warm to preload, or localai model-scout to choose a lighter one.
