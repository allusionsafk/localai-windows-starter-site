How it works

Download. Set up. Chat.

One guided path handles the moving parts and tells you when Windows needs your attention.

  1. 1Download AFK AI

    Get the pinned Friend Beta installer from this site.

    Install AFK AI.cmd

  2. 2Run the guided setup

    AFK AI checks the machine, installs supported prerequisites, and selects a model sized for the detected hardware.

    Windows · Docker · Ollama · model

  3. 3Open local chat

    When setup completes, open Open WebUI at 127.0.0.1:3000. The first Open WebUI account is local to your PC.

    127.0.0.1:3000

First setup downloads several gigabytes. Docker Desktop may need a first launch and Windows may ask for a restart. Hardware virtualization must be enabled. The current Friend Beta still discovers some virtualization, WSL, and Docker blockers later than intended.

Control Center

See what is running.

A local dashboard for health, machine information, model guidance, and privacy-aware support diagnostics.

  • Engine status

    See whether the local model engine and AFK AI services are available.

  • Health checks

    Run the stack checks again and see passing, warning, or failing results.

  • Hardware at a glance

    See the graphics hardware, memory, and the model AFK AI recommends for the machine.

  • Copy Diagnostic Report

    Produce a support summary designed to leave out chats, documents, prompts, credentials, and file contents.

The Control Center is a separate local dashboard. The current installer does not promise to launch it automatically at the end of setup.

Local by default

Keep the model close.

Model inference runs on your own machine. Open WebUI keeps its local account and chat database there too. AFK AI has no cloud account or subscription.

local-first · explicit network boundary

  • Local inference

    Ollama runs the model on your Windows PC. An NVIDIA GPU is recommended; smaller CPU-only models are available as a much slower fallback.

  • Local user-facing services

    Chat, web search, voice, and the Control Center use loopback endpoints. Ollama uses a host bind so Docker can reach it, with a separate Windows Firewall guardrail for physical network adapters.

  • Privacy-aware diagnostics

    Support reports are designed to exclude chats, documents, prompts, credentials, and file contents.

  • The internet is still useful

    Setup, model downloads, and updates use the internet. Optional web search sends queries to external providers through SearXNG. Local-first does not mean permanently offline.
