Runtime truth / 004 states

A requested feature is not reported as active until the runtime proves it.

Requested
What the user asked for: preset, enhancement, motion, HDR or audio behavior.
Planned
What DemiMedia selected after looking at source and machine evidence.
Observed
What the decoder, renderer and presentation path actually reported at runtime.
Fallback
What changed when the preferred path failed, degraded or could not be proven.

Measured boundary

Strong claims stop where the evidence stops.

Reference-first, not Reference-by-default

A dedicated Reference preset exists, but the current UI default/first selection is Automatic. Optional processing remains explicit.

Compatibility export is separate

P7→P8.1 export is a compatibility operation rather than the playback path. FEL export discards FEL picture contribution and must say so.

Hardware chains vary

HDR switching, bitstream/Atmos, RTX paths, decode and renderer behavior depend on the hardware/display/receiver chain.

No current download

The standalone repository has no DemiMedia release yet. Historical Adaptive Media prereleases are provenance, not the current product build.
